# Odin-recipes

* This project demonstrate a simple representation of a recipe page using HTML *

## Description of the project goals :-
 - Create a home html page which contains the 2-3 recipes of different foods
 - Each recipe present as a link to other html page on the "home page"
 - Each recipe have its unique html page with its description, ingredients, step of
 - preparation and a final image of food.


## Skill demonstration :-
 - Basic html and git.
